# NEXUS OS

Personal operating system for execution, projects, time, goals, finance and future AI orchestration.

## v0.1 — Execution Core

- Today command center
- WIP-limited project portfolio
- Project roadmaps and tasks
- Immersive Flow Mode with real timer
- Universal Capture / Inbox
- Calendar, goals, finance, ideas and analytics foundations
- Browser persistence for the first prototype

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Motion · Lucide

## Run

```bash
npm install
npm run dev
```

## Next architecture steps

The browser persistence layer is temporary. The next phase replaces it with Firebase Auth + Firestore, then adds Google Calendar sync, financial records, OpenAI agent capabilities and a NEXUS MCP surface for ChatGPT.
